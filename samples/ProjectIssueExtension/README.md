# 项目问题单扩展

此扩展依附主系统已有的项目编号，管理问题、Q 单号、测试状态、个案与程序信息，并为每张单据维护“变动状态”与“解决描述”。安装包是独立 ZIP，不含客户表格或凭据。

## 安装

1. 先升级网关主程序到包含 `IGatewayExtensionStorage` 的版本。本扩展不能安装到旧版主程序。
2. 执行 `scripts/package-project-issue-extension.ps1`，得到 `artifacts/extensions/project-issue-tracker-1.1.0.zip`。
3. 用管理员账号进入“定制模块”，上传 ZIP 并启用。扩展页面会出现在模块导航中。
4. 先在主系统“项目管理”建立并启用项目，然后在扩展页面选择对应项目。

## 导入

- 支持 `.xlsx`、`.csv`、`.tsv`（单文件不超过 5 MB、一次最多 5000 行），识别前 15 行中的表头。
- 与所给“问题清单”对应的字段：`Q单编号`、`测试状态`、`是否解决`、`类别`、`问题处理人`、`开发说明`、`个案书名`、`程序名称`、`解决描述`、`变动状态`，以及负责顾问、开发人员、备注等。其他列保留在“扩展字段”。
- 在线文档可选中包括表头的数据区域并复制，粘贴到导入框；也可由用户导出 Excel 再上传。可填原始 HTTPS 链接以便追溯。
- 需要登录的金山文档不能由扩展绕过权限自动抓取；当前版本不提供后台定时同步。重复导入按项目 + Q 单号更新；无单号时按来源链接、文件名、工作表和行号更新。
- 导入时“变动状态”列可以为空：为空时保留系统内已有状态（回导不会覆盖人工/AI 维护结果）；携带了状态则按变化语义记录变动时间。

## 变动状态与日报

- “变动状态”是独立于测试状态的跟进状态（如 未处理 → 处理中 → 处理完成），导入或新增时可以为空。
- 只有状态值实际变化时才刷新“变动状态时间”并追加变动记录；修改其他字段（测试状态、解决描述等）不会改变该时间。
- 页面“当天日报”按钮按服务器本地时区归纳当天发生状态变化的单据，并生成可复制的日报文本。
- MCP 工具 `daily_report` 支持 `date`（yyyy-MM-dd，默认当天）参数，供 AI 汇总任意一天。

## MCP 工具（AI）

| 工具 | 说明 |
| --- | --- |
| `list_projects` / `list_issues` / `get_issue` / `summarize_issues` | 只读查询 |
| `daily_report` | 归纳指定日期变动状态发生变化的单据，用于生成日报 |
| `update_issue` | 按单号提交表单维护单据（测试状态、解决描述、变动状态等），仅更新传入字段；单号不存在时自动新建 |
| `set_workflow_status` | 按单号变动变动状态；状态实际变化时自动记录变动时间 |

人工新增、删除、导入（`save_issue`、`delete_issue`、`import_issues`）仅管理员通过扩展页面调用，不注册到 MCP。

## 权限和数据

- 问题数据使用网关现有 Data Protection 密钥加密，保存在网关存储目录 `extensions/.data/project-issue-tracker/issues.json.protected`，不在可替换的插件 ZIP 内；扩展重装不会覆盖数据。迁移到另一台电脑时应连同网关密钥目录一并备份。
- 导入文件只在本地请求中解析，不会上传到外部服务。卸载扩展后数据目录仍保留，需人工备份或清理。
