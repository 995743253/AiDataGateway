# 运行库与数据保存说明

## 推荐下载哪个包

- `self-contained-win-x64`：已内置 .NET 10 Desktop Runtime，不需要安装 .NET；电脑需要已有 WebView2 Runtime。
- `full-offline-win-x64`：同时内置 .NET 10 和 WebView2 Fixed Version Runtime，解压后即可运行，不需要另装运行库。

两个包均仅支持 64 位 Windows 10/11。完整离线包更大，因为微软的 WebView2 Fixed Version Runtime 解压后体积超过 600 MB。

## 数据库保存在哪里

程序自身的 SQLite 管理数据库默认保存在：

```text
%LocalAppData%\AiDataGateway\gateway.db
```

### 更换数据目录

发布目录中提供 `gateway.host.example.json`。复制一份并改名为 `gateway.host.json`，程序下次启动时会读取它：

```json
{
  "storagePath": "data",
  "listenAddress": "127.0.0.1"
}
```

- `data`：保存到软件目录下的 `data` 子目录，推荐用于便携运行；
- `.`：直接保存到软件所在目录；
- `D:\\AiDataGatewayData`：保存到指定绝对目录；
- 相对路径始终以 `AiDataGateway.Desktop.exe` 所在目录为基准。

也可以设置环境变量 `AI_GATEWAY_STORAGE_PATH`。环境变量优先级高于 `gateway.host.json`，配置文件优先级高于默认用户目录。

如果程序位于 `Program Files` 等受保护目录，请不要使用 `.` 或其子目录，否则普通用户可能没有写入权限。建议将软件解压到当前用户有写权限的目录，或继续使用默认用户目录。

### 搬迁已有数据

更改路径不会自动移动旧数据库。保留已有数据时按以下顺序操作：

1. 从系统托盘彻底退出 AiDataGateway；
2. 在目标目录中复制原数据目录的 `gateway.db`、`keys` 目录以及需要保留的 `logs`；
3. 创建 `gateway.host.json` 并设置新目录；
4. 启动软件，确认原账号、数据源和 OAuth2 客户端仍可使用；
5. 确认无误后再处理旧目录备份。

不要只复制 `gateway.db`。其中的数据源密码、Seq API Key 等内容依赖 `keys` 目录解密。切换到一个空目录后再次出现初始化页面是正常行为，表示该目录中还没有管理数据库。

WebView2 浏览器缓存不随 `storagePath` 更改，仍位于 `%LocalAppData%\AiDataGateway\WebView2`；它不保存网关的业务配置。

初始化完成后，关闭程序或重启电脑都不会重新进入初始化页面。程序最小化或点击关闭按钮时会进入系统托盘；需要彻底退出时，请右键托盘图标并选择“退出”。

## 再次出现初始化页面的常见原因

1. 换了 Windows 登录用户，导致 `%LocalAppData%` 指向另一个用户目录。
2. 以不同的 Windows 服务账号或沙箱账号运行程序。
3. 清理工具删除了当前配置的数据目录。
4. 手动删除、移动或损坏了 `gateway.db`。
5. `gateway.host.json` 或 `AI_GATEWAY_STORAGE_PATH` 指向了一个空目录。

如需迁移到另一台电脑，请先完全退出程序，再复制完整数据目录。该目录包含账号、数据源配置、OAuth2 客户端、审批记录和密钥材料，必须按敏感数据保护。

## WebView2 说明

完整离线包内置 WebView2 Fixed Version Runtime `151.0.4129.93 x64`，程序会优先使用它；精简自包含包会使用系统安装的 Evergreen WebView2 Runtime。

Windows 10 上首次使用内置运行时时，程序会为 WebView2 目录补充微软要求的 AppContainer 只读/执行权限。请将压缩包解压到当前用户有写权限的普通文件夹，不要直接在压缩包内运行。
