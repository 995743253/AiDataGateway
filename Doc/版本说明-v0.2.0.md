# AiDataGateway v0.2.0 版本说明

## 新增能力

- 新增 MCP Streamable HTTP Server：`http://127.0.0.1:5127/mcp`；
- MCP 支持 `initialize`、`ping`、`tools/list`、`tools/call` 和初始化通知；
- MCP 内置数据源列表、SQL 校验、只读查询、提交审批和工单状态工具；
- MCP 强制使用 OAuth2 Bearer Token，不接受后台 Cookie；
- 新增 Oracle、MariaDB、达梦 DM8、Firebird 数据源；
- 系统设置新增审批有效期，默认 15 分钟，可配置 1–10080 分钟；
- HTTP API 与 MCP 共用审批提交服务、安全策略、表黑名单、行数限制和审计日志；
- 新增 OAuth 授权服务器和受保护资源发现端点。

## 数据库连接提示

| 类型 | 默认端口 | 数据库字段 |
|---|---:|---|
| Oracle | 1521 | Service Name，例如 `XE`、`ORCLPDB1` |
| MariaDB | 3306 | 数据库名 |
| 达梦 DM8 | 5236 | 数据库名或服务配置名称 |
| Firebird | 3050 | 服务端数据库文件路径或别名 |

## 兼容升级

已有本地 `gateway.db` 不需要重新初始化。程序启动时会自动为设置表补充 `ApprovalExpirationMinutes` 列，默认值为 15；原有用户、数据源、OAuth2 客户端、审批和审计记录不受影响。
