# AiDataGateway v1.0.4 版本说明

## 本次更新

- **发布产物不再进行代码混淆**。混淆自 v0.8.0 引入，但项目源码本就公开，混淆没有实际保护价值，反而带来两个实际问题：v1.0.0~v1.0.2 的字符串混淆损坏了编译器生成类（保存带表黑名单的数据源必现报错，v1.0.3 修复）；混淆特征持续触发 360 等杀软的启发式误报。移除后产物为正常命名的标准 .NET 程序集，杀软兼容性恢复常态。
- 完整性保障不变且不受影响：发布产物继续附带 SHA-256 校验文件，应用内更新流程继续强制校验哈希后才执行安装。 Authenticode 代码签名将在证书采购完成后接入。

## 升级建议

- v1.0.3 用户可直接覆盖升级；不修改 `gateway.db` 结构，本地数据自动保留。
- 升级时若杀软提示，本版本产物为未混淆程序集，正常放行即可；如遇报毒请通过杀软的误报申诉渠道反馈。
