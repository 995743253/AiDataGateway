# AiDataGateway v0.3.3 版本说明

## 本次更新

- 服务器近期趋势和历史趋势新增清晰的 X/Y 坐标轴、刻度线与辅助网格。
- Y 轴根据指标单位自动显示百分比、容量、速率、时长或计数；X 轴根据数据跨度自动显示时间或日期。
- 每条实际采样记录显示为折线节点，鼠标悬浮后展示指标名称、格式化数值和完整采集时间。
- 节点使用扩大后的透明命中区域，密集折线和较小窗口下也更容易悬浮选择。
- 优化提示卡片边缘定位，首尾节点或高位节点的提示不会轻易超出图表区域。

## 兼容与升级

- 本次仅更新趋势图交互和显示，不修改数据库结构，无需重新初始化 `gateway.db`。
- 近期、历史查询接口和远端 Agent 协议保持兼容。
