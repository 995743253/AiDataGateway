# AiDataGateway v1.0.2 版本说明

## 本次更新

- 应用日志事件新增独立 `sql` 栏位：查询与实时推送时自动从结构化属性（sql / query / commandText 等）或消息文本中提取 SQL 语句，日志表格新增"SQL"列，含 SQL 的行可直接"查看 SQL"。
- SQL 分析窗口支持参数化查询：SQL 含 `?` 占位符时显示占位符数量，提供逐个参数栏位（留空=空串、填 null=NULL、数字自动识别）；执行时由网关按位置安全替换为 SQL 字面量，单引号自动转义，字符串内部的 `?` 不参与计数与替换。
- 参数支持 JSON 一次填入：按位置数组 `["值1", 2]` 或按序号对象 `{"1": "值1"}` 两种写法，一键应用到参数栏位。
- 参数数量与占位符数量不一致时直接拒绝执行（HTTP 400）并提示数量；替换后的完整 SQL 仍经过只读策略校验、表黑名单和最大返回行数限制，执行与拦截均写入审计日志。
- SQL 提取逻辑同步作用于 AI 客户端接口（`/api/gateway/logs/query`）与 MCP `query_logs`，返回事件同样携带 `sql` 字段。

## 兼容与升级

- 不修改 `gateway.db` 结构，无需重新初始化数据库。
- 前端旧的本地 SQL 识别逻辑保留为兜底：后端未返回 `sql` 字段的历史数据仍可在页面上识别。
