# AiDataGateway v1.0.5 版本说明

## 修复

- **修复应用日志"完整数据"弹窗无法打开**：v1.0.2 起，前端把参数化查询的两个辅助函数误置于计算属性块，导致点击"完整数据"时抛出 `TypeError: this.countSqlPlaceholders is not a function`，详情弹窗无法打开（所有日志源类型均受影响，含 Seq / 本地 NLog / 远程 Agent）。本版本将函数归位到 methods，弹窗恢复正常。
- 随 v1.0.2~v1.0.4 发布的所有用户均建议升级；不修改 `gateway.db` 结构，本地数据自动保留。
