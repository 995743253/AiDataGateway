# AiDataGateway v1.0.3 版本说明

## 修复

- **修复新增/编辑数据源保存失败**：v1.0.0 起，发布流程的字符串混淆（Obfuscar HideStrings）会损坏 .NET 10 程序集中编译器生成的 lambda 闭包类，导致保存带表黑名单的数据源时报错 `Could not load type '<>c' ... because the format is invalid`。本版本关闭字符串加密（类型/方法名混淆不受影响），并修复该损坏。
- **发布冒烟测试加固**：冒烟测试此前只验证服务启动与界面构造，未覆盖数据源保存路径。现在会真实创建带表黑名单的数据源并验证规范化结果，此类混淆损坏今后会在 CI 阶段被拦截。

## 升级建议

- v1.0.0 ~ v1.0.2 均受同一混淆问题影响（保存带表黑名单的数据源必现报错），建议所有用户升级到 v1.0.3。
- 不修改 `gateway.db` 结构，无需重新初始化数据库；安装器可直接覆盖升级，本地数据自动保留。
