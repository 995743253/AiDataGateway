# AiDataGateway 安装与自动更新说明

## 1. 发布文件

GitHub Release 提供三类文件：

- `AiDataGateway-Setup-v版本-win-x64.exe`：推荐给普通用户，支持首次安装、覆盖更新和卸载。
- `AiDataGateway-v版本-win-x64.zip`：绿色版，解压即用，不自动登记安装目录。
- `AiDataGateway-MonitorAgent-v版本-win-x64.zip`：远端服务器监控与本地日志采集 Agent。

每个文件均附带 `.sha256` 校验文件。应用内更新会校验安装器 SHA-256，校验失败不会运行。

## 2. 首次安装

运行 Setup 后可分别选择：

1. 程序安装目录，默认 `%LocalAppData%\Programs\AiDataGateway`。
2. 数据库与密钥目录，默认 `%LocalAppData%\AiDataGateway`。

安装器会在程序目录写入 `gateway.host.json`，其中 `storagePath` 指向选择的数据目录。该目录包含 `gateway.db`、`keys` 和网关日志，必须整体备份。

数据库目录不能与程序目录完全相同；如果希望数据跟随软件目录，建议选择 `程序目录\data`。这样覆盖升级不会碰数据，卸载时也能明确保留该子目录。

## 3. 覆盖更新

安装器在当前用户注册表的 `HKCU\Software\AiDataGateway` 中记录程序目录、数据目录和版本。再次运行新版 Setup 时会自动进入更新模式：

- 程序目录和数据库目录自动回填并锁定；
- 原有 `gateway.host.json` 保留；
- 只覆盖程序文件；
- 不删除 `gateway.db`、`keys` 和日志；
- 更新前若程序仍在运行，会提示从托盘退出。

## 4. 应用内更新

桌面端启动后会查询 `995743253/AiDataGateway` 的最新 GitHub Release。也可以点击窗口右下角或托盘菜单中的“检查更新”。

发现新版后，程序会下载 `AiDataGateway-Setup-*-win-x64.exe`，验证 GitHub Release 提供的 SHA-256，然后启动静默更新。安装器等待旧进程退出，再更新原安装目录并重新启动程序。

如果使用绿色版，注册表中没有安装信息，应用内安装器无法判断目标目录；建议绿色版用户手动下载新版 ZIP，或先运行 Setup 转为安装版。

## 5. 卸载

可以从 Windows“设置 → 应用 → 已安装的应用”卸载。卸载程序默认保留数据库与密钥目录，避免误删业务数据；确认不再需要后可手动删除数据目录。

## 6. GitHub 自动发布

仓库的 `.github/workflows/release.yml` 支持：

- 手动运行工作流，仅生成可下载的 Actions Artifact；
- 推送 `v*` 标签时自动创建 GitHub Release 并上传安装器、绿色版、Agent 和校验文件。

本地生成命令：

```powershell
./build/Publish-Release.ps1 -Version 0.7.0
```

输出位于 `artifacts/release`。

> 当前安装器未做商业代码签名。首次从互联网下载时 Windows SmartScreen 可能显示“未知发布者”。正式分发前建议购买代码签名证书，并在发布工作流中对桌面程序与安装器签名。
