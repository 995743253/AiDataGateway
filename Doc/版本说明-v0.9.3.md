# AiDataGateway v0.9.3 版本说明

## 本次更新

- 新增“工具箱”功能组（独立分层，不影响核心网关功能），包含 WebHook 调试与格式化/编码工具。
- **WebHook 调试**：创建接收地址（`http://<网关地址>/toolbox/hook/<令牌>`）供外部系统推送请求；支持手动启用/停用、查看历史报文（方法、查询参数、Content-Type、报文头与正文，正文超长自动截断标记）、一键清空报文；删除 WebHook 会级联删除其全部历史报文，报文仅支持手动清理。
- **格式化与编码工具**（纯本地处理，内容不出本机）：XML 格式化、JSON 格式化、大小写转换（大写/小写/下划线↔驼峰）、Base64 编解码。
- 修复 WebHook 报文落库时序问题；管理接口需登录，接收入口按设计匿名开放（凭令牌路由）。

## 兼容与升级

- 升级时自动创建工具箱所需数据表（`GatewayToolboxWebHooks` / `GatewayToolboxWebHookDeliveries`），不影响既有功能与数据。
- 已安装 v0.9.2 的用户会通过内置自动更新收到本版本。
