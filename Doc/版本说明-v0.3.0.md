# AiDataGateway v0.3.0 版本说明

## 主要新增

- 项目管理：通过唯一项目编号聚合数据库、NLog/Seq 日志源和服务器监控节点，三类资源均支持多对多关联。
- 应用日志：支持本地 NLog 容错解析和 Seq API 查询；一条 Seq 日志源对应一个加密 API Key。
- 服务器监控：内置 25 项 CPU、内存、Swap、磁盘、网络速率、进程、TCP 和 .NET GC 指标；每个节点可独立选择采集项。
- 趋势分析：支持近期实时趋势和按起止时间查询的历史趋势，完整时间范围会自动压缩为适合绘图的点数。
- 远端采集：新增自包含 `AiDataGateway.MonitorAgent`，每个远端节点使用独立且只显示一次的上报密钥。
- 局域网监听：默认仍仅监听 `127.0.0.1`；设置 `AI_GATEWAY_LISTEN_ADDRESS=0.0.0.0` 并重启后可接收可信内网 Agent 上报。
- AI 接口：REST 和 MCP 新增按项目读取日志及服务器指标的能力。
- 自动维护：统一保留策略会同时清理过期审批、网关审计、服务器指标和本地日志文件。

## 兼容与升级

- 不需要重新初始化现有 `gateway.db`。
- 首次启动 v0.3.0 时会自动补建项目、日志源、监控节点和指标表。
- 已有监控表会自动增加指标选择和扩展指标 JSON 列，不需要重新初始化数据库。
- 现有用户、OAuth2 客户端、数据源、审批和审计记录保持不变。
- 新建 AI OAuth2 客户端默认包含 `gateway.logs.read` 和 `gateway.metrics.read`；旧客户端需要在确有读取指标需求时重新创建或调整 Scope。

## 发布目录

- `AiDataGateway.Desktop.exe`：自包含桌面网关。
- `MonitorAgent/AiDataGateway.MonitorAgent.exe`：自包含远端监控 Agent。
- `Doc/`：完整使用、AI API、MCP、日志和服务器监控说明。

自包含版本不要求安装 .NET 10 Desktop Runtime。桌面内嵌页面仍需要 WebView2 Runtime；Windows 11 通常已预装，若被精简或卸载则需单独安装。
