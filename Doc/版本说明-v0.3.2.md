# AiDataGateway v0.3.2 版本说明

## 本次更新

- 日志源配置明确拆分为“本地文件夹（NLog）”与“Seq HTTP API”两种互斥采集方式。
- 本地 NLog 可直接填写网关电脑上的日志文件夹，默认读取目录顶层最近修改的 `*.log` 文件；仍支持完整文件名和通配符。
- Seq 模式明确通过 `GET /api/events` 查询，并为每条日志源保存一个独立、加密的 API Key。
- 日志源列表、配置弹窗、应用日志选择框和查询提示都会持续显示当前采集方式。
- 修复 Element Plus 采集方式控件未正确呈现的问题，并优化日志源弹窗的内部滚动和底部操作区。

## 兼容与升级

- 不需要重新初始化 `gateway.db`，已有日志源仍按原 `Type` 值识别为本地 NLog 或 Seq。
- 不修改已有日志源的文件路径、Seq 地址、API Key、项目关联或启停状态。
- 原先填写完整日志文件路径或通配符的本地日志源可继续使用。
