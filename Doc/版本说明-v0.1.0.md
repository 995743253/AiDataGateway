# AiDataGateway v0.1.0 版本说明

## 版本定位

这是 AiDataGateway 的第一个可运行版本，面向 Windows 本地 AI 编程助手，提供数据库访问管控、OAuth2 鉴权和人工审批能力。

## 运行环境

- Windows 10/11 x64；
- .NET 10 Desktop Runtime；
- Microsoft Edge WebView2 Runtime；
- 默认服务地址：`http://127.0.0.1:5127`。

## 主要功能

- WinForms 桌面宿主和系统托盘；
- Vue 3 + Element Plus 管理页面；
- 用户、密码、角色和登录锁定管理；
- OpenIddict OAuth2 Client Credentials；
- SQL Server、MySQL、PostgreSQL、SQLite 数据源；
- 只读 SQL 查询和最大返回行数限制；
- `INSERT`、`UPDATE`、`DELETE`、`CREATE TABLE` 人工审批；
- 无 `WHERE` 的 `UPDATE`/`DELETE` 拦截；
- 危险 DDL、授权语句和多语句拦截；
- 本地 SQLite 配置库；
- 数据库密码加密存储；
- 操作审计记录。

## 快速启动

1. 解压整个压缩包；
2. 双击 `AiDataGateway.Desktop.exe`；
3. 按页面提示创建管理员；
4. 立即保存首次显示的 OAuth2 Client ID 和 Client Secret；
5. 登录后注册数据源并测试连接；
6. 按《小白使用说明：客户端操作与 AI 接入》配置 AI。

不要只复制 EXE 文件，程序依赖同目录下的 DLL、`runtimes` 和 `wwwroot`。

## 本地数据

用户数据不会保存在程序解压目录，而是默认保存在：

```text
%LocalAppData%\AiDataGateway
```

升级或重新解压程序不会自动删除已有配置。备份时应同时备份 `gateway.db` 和 `keys` 目录。

## 当前限制

- 当前是 HTTP/JSON API，尚未内置 MCP Server；
- AI 提交审批后尚无状态轮询接口；
- OAuth2 客户端尚无删除、禁用和 Secret 轮换页面；
- 审计记录尚无查询页面/API；
- 配置数据库升级暂未使用 EF Core migrations；
- 默认仅适合本机回环访问，不应直接暴露到公网。
