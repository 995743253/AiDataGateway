# AiDataGateway v0.3.1 版本说明

## 本次更新

- 每个本地或远端监控节点可从 25 项系统指标中独立选择采集项，CPU、内存、磁盘和系统运行时间等基础心跳指标保持必选。
- 监控页面新增动态指标卡片，并可选择任一已启用指标绘制趋势。
- 近期趋势展示最近 120 个采样点；历史趋势支持选择起止时间，最长查询 31 天。
- 历史数据会读取完整时间范围，并最多均匀压缩为 500 个绘图点，同时显示原始记录数与实际趋势点数。
- 远端 Agent 会从网关同步指标配置；配置变化通常在 5 分钟内生效。
- 优化指标配置弹窗和趋势工具栏，在 WinForm 内嵌网页及较窄窗口下支持内部滚动和自动换行。

## 兼容与升级

- 不需要重新初始化 `gateway.db`，程序启动时会自动补充监控配置和扩展指标字段。
- 现有监控节点会自动使用推荐指标集合，原有用户、数据源、审批、OAuth2 客户端和日志记录不受影响。
- 桌面端和 `MonitorAgent` 均为自包含发布，目标系统仍需具备 WebView2 Runtime 才能显示内嵌管理页面。
