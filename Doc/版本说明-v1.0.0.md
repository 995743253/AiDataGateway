# AiDataGateway v1.0.0 版本说明

## 定制化模块

- 新增“定制化模块中心”，管理员可上传包含后端 DLL 与前端静态制品的 ZIP 扩展包。
- 扩展页面自动嵌入右侧多页签工作区；模块可启用、停用、热更新和删除，无需把企业私有规则合入主仓库。
- 扩展工具会动态加入 MCP `tools/list`，公开名称统一使用 `custom_*` 前缀，并沿用 OAuth2 Scope 权限检查。
- 提供稳定的 `AiDataGateway.Extensions.Abstractions` v1 进程内契约，支持项目级只读数据库查询、结构化日志读取和本机/远端监控指标读取。
- 数据库凭据不会公开给扩展；通过上下文执行的 SQL 仍受项目关联、只读策略、表黑名单、行数限制、超时和审计保护。
- 安装包加入“本机监控分析报告”示例扩展，可生成健康评分、指标趋势、风险结论和供 AI 使用的 Markdown 报告。
- 新增《定制化模块开发指南》，公开扩展包格式、接口清单、权限能力、MCP 命名和前端接入方式。

## 管理员密码恢复

- 登录页新增“忘记管理员密码”入口，可使用独立重置口令修改已启用 Administrator 账号的登录密码。
- 初始重置口令为 `admin`；系统设置新增“管理员密码恢复”区域，可设置 4–128 位自定义重置口令。
- 自定义重置口令通过本机 Data Protection 加密存储，接口不返回原值。
- 管理员密码重置接口每分钟最多尝试 5 次；口令校验、重置结果和设置变更均写入审计日志。

## 登录体验

- 用户登录密码规则放宽为至少 6 位，不再强制同时包含大写字母、小写字母和数字；中文、英文、数字和符号均可使用。
- 登录页新增“记住密码”选项。开启后使用受保护的 Identity 持久登录 Cookie 在本机保持登录 30 天，不会在前端保存明文密码。

## 安全说明

- 定制化 DLL 是进程内受信任代码，并非沙箱；只能安装来源可信且经过审核的扩展包。
- 默认管理员重置口令便于首次恢复，但安全性较低。升级后请尽快登录系统设置，将 `admin` 修改为仅本人知晓的强口令。

## 兼容与升级

- 可从 v0.10.x 直接升级，无需重新初始化数据库。
- 首次启动 v1.0.0 时会自动为原有 SQLite 数据库增加管理员重置口令字段，已有用户、OAuth2 客户端、数据源、项目、日志、审批和指标记录不受影响。
- 安装器会保留既有程序目录和数据库目录，内置自动更新可识别 v1.0.0。
