# AiDataGateway v0.10.1 版本说明

## 本次更新

- “立即更新”按钮支持鼠标悬浮预览版本更新内容：悬浮时在按钮上方弹出更新说明卡片（标题 + 正文），移开或点击任意位置自动关闭。
- 更新说明自动清理 Markdown 标记（标题符号、列表符号、加粗星号、链接只保留文字）。
- 检查更新遇到 GitHub API 限流时自动回退到 releases 订阅源，并从订阅源解析更新说明。
- 发布工作流优先使用 `Doc/版本说明-vX.Y.Z.md` 作为 Release 说明正文，悬浮弹窗与 Release 页面展示一致的中文说明。

## 兼容与升级

- 不修改 `gateway.db` 结构，无需重新初始化数据库。
- 已安装 v0.10.0 的用户会通过内置自动更新收到本版本，程序目录和数据库目录保持不变。
