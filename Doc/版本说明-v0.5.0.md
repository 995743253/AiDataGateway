# AiDataGateway v0.5.0 版本说明

## 日志能力

- 修复 NLog `<variable>` 引用未展开的问题，支持 `${Layout}`、`${LogTxtLocation}` 等递归变量。
- 日志文件自动识别 UTF-8、BOM 和 GB18030/GBK，中文日志不再乱码。
- 本地日志先按日期筛选候选文件，再执行 8 MB 内存上限读取；页面默认最近 24 小时，接口默认最近 7 天，单次最长 31 天。
- Seq 增加适合新手的关键词和属性查询，高级 Seq Filter 仍可使用；日期条件直接下推到 Seq。
- 应用日志页面增加 SSE 实时查看，客户端最多保留最近 500 条，避免内存持续增长。

## 远程日志采集

- `AiDataGateway.MonitorAgent` 除服务器指标外，可读取所在服务器的本地 NLog 文件。
- 网关新增“远程 Agent”日志源，通过独立密钥按需查询，不预先全量上传日志。
- 发布时额外生成独立、自包含的 Monitor Agent 压缩包，便于复制到远程 Windows 服务器。

## 兼容与升级

- 不修改现有 `gateway.db` 表结构，无需重新初始化数据库。
- 现有本机 NLog、Seq、REST 和 MCP 配置保持兼容；`query_logs` 新增可选的 `searchText`、`propertyName`、`propertyValue`。
