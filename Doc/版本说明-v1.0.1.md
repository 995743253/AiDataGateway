# AiDataGateway v1.0.1 版本说明

## 发布制品保护

- 正式发布流程新增 .NET 程序集混淆，对桌面端、应用层、领域层、基础设施层、监控组件和远程采集端隐藏内部类型、参数与字符串。
- 保留公开 API、JSON/EF 属性、WPF 事件和扩展契约名称，避免混淆破坏数据库映射、页面资源以及企业扩展兼容性。
- 打包前会直接启动混淆后的程序，检查 Web API、SQLite 初始化和 WPF/BAML 资源；自检失败或超过 60 秒会中止发布。
- 混淆映射只写入本地 `artifacts/obfuscation-maps`，不会加入便携 ZIP、安装器、工作流制品或 GitHub Release。
- 新增私有扩展包保护脚本，企业模块可以在上传前单独混淆入口 DLL及自有依赖。

## 保护边界

- 混淆用于增加直接反编译二进制制品的成本，不能保证代码绝对不可恢复。
- 主仓库中已经公开的源码仍然可以直接阅读；公司专有算法和元数据规则应放在不公开的定制化模块中，再对其发布包执行混淆。
- 密码、API Key、证书私钥等秘密不得硬编码进 DLL，字符串隐藏不能代替凭据加密。

## 兼容与升级

- 本次不修改 `gateway.db` 结构，无需重新初始化数据库。
- 现有定制化模块接口保持不变。
