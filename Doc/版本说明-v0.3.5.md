# AiDataGateway v0.3.5 版本说明

## 本次更新

- “近期趋势”改为按采样顺序均匀铺开，解决软件停机后再次启动时新采样点堆叠在图表一侧的问题。
- “历史趋势”继续按真实采集时间定位，仍可准确观察采样间隔和数据空档。
- Y 轴根据当前指标数值范围自适应缩放，并生成易读刻度，避免百分比小幅波动被固定 `0–100%` 范围压扁。
- 趋势摘要会明确提示当前采用“按采样顺序展开”或“按真实时间定位”。
- 保留等比缩放、X/Y 轴、面积渐变和节点悬浮详情。

## 兼容与升级

- 本次只修改前端趋势图逻辑，不修改数据库结构和接口，无需重新初始化 `gateway.db`。
