# AiDataGateway v1.0.6 版本说明

## 本次更新

### 新增：项目问题单定制模块

- 集中管理问题与 Q 单号：支持 Excel/CSV 导入，以及在金山文档等在线表格中选中表头和数据区域复制后直接粘贴导入；按项目 + 单号自动去重更新。
- 每张单据可维护**变动状态**（如 未处理 → 处理中 → 处理完成）与**解决描述**。变动状态只在值实际变化时刷新"变动状态时间"并记录完整变动历史；修改其他字段不会改变该时间。
- 内置**当天日报**：归纳当天发生变动状态变化的单据，支持跨所有项目汇总，生成可复制的日报文本。
- AI 协作：通过 MCP 暴露 `update_issue`（按单号提交表单维护/新建单据）、`set_workflow_status`（按单号变动状态）、`daily_report`（日报归纳）工具，便于后续由 AI 从其他系统获取数据并回填维护；人工的新增、删除、导入仅限管理员在页面操作。
- 插件包 `project-issue-tracker-1.1.0.zip` 需搭配本版本及以上主程序使用。

### 定制模块框架增强

- 新增扩展私有加密存储（`IGatewayExtensionStorage`）：数据由网关 Data Protection 密钥加密，保存在存储目录 `extensions/.data/` 下，升级或重装扩展不丢数据。
- 扩展工具支持 MCP 可见性声明；人工写入类操作仅限管理员通过页面调用，不再注册给 AI。
- 修复：安装扩展后主程序启动可能无窗口、端口不监听的问题（启动链路在 WPF 同步上下文下的死锁）。

### 新增：本地日志查看器（独立应用）

- 全新独立 WPF 应用，无需启动网关即可本地查看 NLog 日志。
- 支持多套日志源配置档案，数据库凭据使用 Windows DPAPI 加密保存。
- 结构化字段树展示、SQL 自动提取与只读试查、工作台标签页可分离为独立窗口。
- 自绘标题栏与整体主题美化，与主程序风格统一。

## 升级建议

- v1.0.5 用户可直接覆盖升级；不修改 `gateway.db` 结构，本地数据自动保留。
- 从旧版本升级后，如需使用"项目问题单"模块，请在"定制化模块"中上传随附的 `project-issue-tracker-1.1.0.zip`。
