# AiDataGateway v0.7.0 版本说明

## 本次更新

- 新增自包含 Windows 安装器，可分别选择程序目录和数据库目录。
- 自动识别既有安装位置，覆盖更新时保留数据库、加密密钥和 `gateway.host.json`。
- 注册 Windows 已安装应用与卸载入口，卸载默认保留业务数据。
- 桌面端新增启动检查、底部按钮和托盘“检查更新”。
- 支持从 GitHub Releases 下载新版安装器并校验 SHA-256 后静默更新。
- 新增 GitHub Actions 发布工作流，同时生成安装器、绿色版 ZIP 和独立 Monitor Agent。
- 修复实时日志在没有新数据时无法及时进入已连接状态、可重复点击开始的问题。

## 升级说明

- 不修改 `gateway.db` 结构，无需重新初始化。
- 绿色版首次转安装版时，请在安装器中选择现有数据库所在目录。
