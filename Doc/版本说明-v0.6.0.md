# AiDataGateway v0.6.0 版本说明

## 本次更新

- 桌面壳从 WinForms 迁移到 WPF：无边框窗口改用 WindowChrome 原生拖拽/缩放，渐变标题栏、加载页和底部状态栏全部矢量样式重绘，Win11 自动圆角。
- 内存悬浮球重写为矢量圆环，尺寸与旧版一致；拖动指哪跟哪，位置跨显示器/DPI 缩放正确定位并持久保存。
- 托盘右键菜单品牌化美化：圆角卡片、悬停高亮、内存球开关显示勾选；修复从托盘退出后进程残留的问题（最长 3 秒内干净退出）。
- 管理页面品牌色统一为网关蓝，新增亮色/暗色主题切换（头部 🌙/☀️，记忆用户选择）；日期选择器中文化；卡片、表格、滚动条、弹窗整体美化。

## 兼容与升级

- 不修改 `gateway.db` 结构，无需重新初始化数据库。
- 仍支持 `self-contained-win-x64` 与内置 WebView2 运行时；悬浮球旧位置记录会自动钳制回屏幕内，拖动一次后保存新位置。
