# AiDataGateway v0.4.0 版本说明

## 本次更新

- 新增 Windows 桌面内存使用悬浮球，实时显示物理内存使用率以及已用/总容量。
- 系统设置新增即时开关；普通外部浏览器不能控制本机悬浮窗。
- 悬浮球支持始终置顶、鼠标拖动、位置记忆、双击打开控制台和右键关闭。
- 系统托盘菜单增加“显示内存悬浮球”快捷开关。
- 开关及位置保存在数据目录的 `desktop.settings.json`，软件重启后自动恢复；显示器布局变化后会确保悬浮球仍位于可见区域。
- 内存数据直接从 Windows 读取，不经过 Web API，也不写入审计或服务器指标数据库。

## 兼容与升级

- 不修改 `gateway.db` 结构，无需重新初始化数据库。
- 功能仅在 WinForms 桌面客户端中可用；从普通浏览器访问管理页面时开关保持禁用。
