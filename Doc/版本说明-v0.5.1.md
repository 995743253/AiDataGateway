# AiDataGateway v0.5.1 版本说明

## 本次更新

- 本地 NLog 除 Layout 字段外，新增消息来源/版本、`key=value` 和内嵌 JSON 顶层属性提取，详情页按键值对显示。
- 配置的 Layout 与实际日志格式不一致时，自动按 `时间|级别[线程][来源] 消息|异常` 的常见 NLog 格式兜底解析，避免级别和字段错乱。
- 本地日志单次读取上限调整为 10 MB，包含正好 10 MB；仍先按日期筛选文件。
- 实时日志从历史查询中拆分为独立页面，修复 SSE 字段大小写导致 Seq 实时事件不显示的问题。
- 实时页支持日志源、关键词、级别和 Seq 属性筛选，最多保留最近 500 条。
- OAuth2 客户端支持编辑名称和权限 Scope；保存后撤销旧 Token，但保留原 Client ID 和 Client Secret。
- 应用日志点击“查询”会自动选择并加载可用日志源，不再要求先点“测试”。

## 兼容与升级

- 不修改 `gateway.db` 结构，无需重新初始化数据库。
- 已有 OAuth2 客户端可直接编辑；修改权限后 AI 需要重新申请 Token。
