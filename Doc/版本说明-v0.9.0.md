# AiDataGateway v0.9.0 版本说明

## 本次更新

- 全局响应式布局重构：头部与侧边栏固定，仅内容区滚动；服务器监控页在宽屏下摘要卡与趋势图并排展示，不再需要长距离滚动。
- 侧边栏菜单更换为 Element Plus 矢量图标，修复滚动时侧边栏上移错位的问题。
- 应用日志完整数据、SQL 审批详情、网关审计详情弹窗新增“全屏”切换按钮，可一键铺满整个窗口后再还原。
- 日志结构化属性的值检测到 JSON 时提供“格式化查看”（键值着色、可复制）；检测到 SQL 时提供“SQL 预览”（关键字着色），均在独立小弹窗中展示。
- Seq 日志新增 Topic 列与 Topic 筛选框（应用日志与实时日志页均支持），筛选条件在简单查询模式下优先生效。

## 兼容与升级

- 不修改 `gateway.db` 结构，无需重新初始化数据库。
- 已安装 v0.8.x 的用户会通过内置自动更新收到本版本，程序目录和数据库目录保持不变。
