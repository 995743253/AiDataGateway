# AiDataGateway v0.8.0 版本说明

## 本次更新

- 重新设计亮色、暗色模式下的页面滚动条，并统一 Element Plus 滚动区域样式。
- 项目、数据源、日志源、监控节点、指标明细、实时日志、用户和 OAuth2 客户端等列表新增分页。
- 应用日志、审批记录和网关审计改为带页码、每页条数和跳页输入的标准分页控件。
- 应用日志结构化属性及 SQL 查询结果弹窗新增明细分页，避免大结果集挤满窗口。
- 设置页面新增软件数据库目录迁移，可迁移内置 SQLite 数据库、加密密钥和业务日志。
- 数据库迁移采用停服务、临时目录复制、完整性校验、切换配置和自动重启流程；原目录保留为备份。
- 清理提示和结果补充服务器指标数量，并增加自动化测试验证指标使用统一的保留天数。

## 升级说明

- 从 v0.7.x 升级无需重新初始化数据库。
- 已安装版本可使用应用内“检查更新”，也可直接运行新版安装器覆盖升级。
- 数据库迁移仅能在 Windows 桌面客户端的“系统设置”中执行；浏览器页面不提供迁移权限。
- 如果使用 `AI_GATEWAY_STORAGE_PATH` 环境变量指定数据库目录，请继续通过环境变量管理路径。
