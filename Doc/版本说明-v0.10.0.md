# AiDataGateway v0.10.0 版本说明

## 本次更新

- 新增**定制化模块**框架：管理员在“定制化模块 → 模块中心”上传扩展 ZIP（≤100 MB），即可为管理端增加嵌入式页面，并向 AI 的 MCP 动态注册 `custom_*` 工具，模块启停、删除即时生效且无需重启网关。
- 扩展通过公开契约 `IGatewayExtension` + `IGatewayExtensionContext` 访问网关能力；数据库查询仍经过项目关联校验、只读 SQL 校验、表黑名单、最大返回行数、超时与审计，网关不会向扩展暴露数据库密码、Seq API Key 等凭据。
- 内置示例模块“本机监控报告”（源码随安装包 `samples/` 目录与 Release 资产 `local-monitor-report-1.0.0.zip` 分发）：读取本机/远端指标生成健康评分、趋势图与 Markdown 报告。
- MCP `tools/list` 现在包含已安装模块的 `custom_*` 工具（按调用者能力过滤），`tools/call` 直接调用。
- 扩展目录位于数据目录 `extensions/` 下，随存储迁移一起搬迁；开发指南见 `Doc/定制化模块开发指南.md`。

## 兼容与升级

- 升级自动创建扩展注册表与目录，不影响既有功能与数据。
- 扩展 DLL 为进程内受信任代码，请只安装来源可信、经过审核的扩展包。
- 已安装 v0.9.x 的用户会通过内置自动更新收到本版本。
