# AiDataGateway v0.9.2 版本说明

## 本次更新

- 列表页固定高度：页面不再随列表变长而整体滚动，列表在自身区域内滚动并保持表头固定。
- 服务器监控拆分为“实时概览 / 趋势分析 / 采样明细”三个子页；趋势分析支持同时显示最多 4 个可配置指标的趋势图（网格布局，选择记忆在本地）。
- 应用日志详情重构为“概览 / 结构化属性 / SQL 分析 / 原始记录”子页；自动识别消息中的 SQL 并格式化着色，只读语句可选择该日志源关联项目下的数据源尝试只读执行（仍经过网关 SQL 安全检查、表黑名单与最大行数限制），结果分页展示，数据源候选仅来自日志源关联的项目。
- 列表单元格超长内容不再使用悬浮提示：超出部分截断显示，通过“查看”按钮在弹窗中阅读完整内容。

## 兼容与升级

- 不修改 `gateway.db` 结构，无需重新初始化数据库。
- 已安装 v0.9.x 的用户会通过内置自动更新收到本版本。
